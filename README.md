# SysTech-AutoClick-AutoAd
Minecraftta PvP'de blok dizme veya vurma için işe yarar. Veyahut Skyblock gibi sunucularda otomatik reklam yapmayı dener.

[![Python Version](https://img.shields.io/badge/python-3.14-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

# SysTech-AutoClick-AutoAd nedir?
Bu sistem, Minecrafttaki multiplayerli serverlerde çalışan makro sistemidir. PvP, Bedwars, The Bridge gibi durumlarda blok koyma makrosu ve hasar makrosu yapar. Diğer durumlarda ise (Skyblock, SMP orderleri gibi) belirlediğiniz saniyede bir kez çalışır.

# Kod neden yapay zeka?
Kodumuzu **kütüphane kullanımları için** yapay zeka kullandık ancak gelişirsek yapay zekasız bir şekilde sizlere sunacağız.
